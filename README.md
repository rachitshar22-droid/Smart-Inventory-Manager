# Smart Inventory Manager

Most businesses lose money on "Dead Inventory" — stock that just sits in the warehouse, takes up space, and never moves. 
I built this B2B SaaS to solve exactly that problem. 

It's a full-stack MERN application that tracks stock, automates status updates, and prevents inventory from rotting on the shelves. 
Built with a focus on a minimal UI and a solid backend.

## Tech Stack
* **Frontend:** React, Vite (Simple, clean, no-nonsense UI)
* **Backend:** Node.js, Express
* **Database:** MongoDB
* **Auth:** JWT (JSON Web Tokens) & bcrypt 

## What It Actually Does
* **Kills Dead Inventory:** Tracks what's moving and what's stuck in the warehouse.
* **Automated Cron Jobs:** Runs background scripts to automatically update inventory status so you don't have to do it manually.
* **Custom Auth Flow:** Secure login with salted passwords and proper CORS handling.
* **Core API:** Solid CRUD operations for managing B2B stock logs.
